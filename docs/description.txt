Table Filter adds in-page filtering controls for HTML tables.

Current feature:
- Hide rows when a selected column equals a selected value (exact match, case-insensitive)

How it works:
- Open the Table Filter panel from the extension action
- Choose the table
- Choose the column
- Enter the value to hide
- Matching rows are hidden immediately
- Clear restores all rows

Current scope:
- Works on pages with one or more HTML table elements
- Handles multiple tables on one page
- Runs fully in browser on the active page

Privacy:
- Table content is processed locally in your browser.
- No user data is transmitted to our servers.
