Table Filter scans the current page table into a local in-browser view so you can filter and sort it without relying on the site's own table UI.

Current features:
- Full-table scan for virtualized HTML tables
- Local text search
- Local multi-select Status filter
- Local numeric Unwatched filter
- Local sorting for all visible non-image columns
- Rescan to rebuild from the page's current dataset

How it works:
- Click the extension action
- Table Filter scans the full current table
- The extension replaces the table controls with local controls
- Filtering and sorting then run on the local cached table

Current scope:
- Works entirely in the browser on the active page
- Designed for HTML tables, including virtualized table views
- Current workflow is tuned for pages like trackseries.tv/myshows

Privacy:
- Table content is processed locally in your browser.
- No user data is transmitted to our servers.
